# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

vwatcher is a full Python rewrite of the original application "vwatch" written in Tcl and Perl.
This changelog only details changes made after the rewrite.

This project uses [*towncrier*](https://towncrier.readthedocs.io/) and the changes for the upcoming release can be found in <https://github.com/Uninett/vwatcher/tree/main/changelog.d/>.
